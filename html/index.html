Security

Hardening choices in this web build.

  • Strict CSP, no remote scripts, and no inline event handlers.
  • Local storage only for favorites and browsing history.
  • Safe link handling with `rel="noreferrer noopener"` on external targets.
  • Input is escaped before rendering into the page.
  • Static server path normalization blocks traversal.
